✨ 적분과 미분의 관계

Δx → 0이면 ΔS ÷ Δx → f(x)이므로, S(x)를 x에 대하여 미분하면 f(x)가 돼요.

S(x)의 x에서의 순간변화율은 함숫값 f(x)와 같아요. 즉, S(x)의 접선의 기울기 = f(x).

    탭다루는 개념학생이 하는 일
    ① 관찰S(x) = ∫ax f(t)dt, ΔS와 mΔx ≤ ΔS ≤ MΔxΔx를 1 → 0.01로 줄이며 ΔS ÷ Δx가 f(x)에 가까워짐을 관찰, 할선이 접선으로 바뀌는 모습 확인
    ② 조작적분과 미분의 관계, 미정계수 구하기(S = 2x³ − x − 1), 접선의 기울기일차·이차 f(t)와 아래끝 a를 바꾸며 S'(x) = f(x), S(a) = 0, a를 바꾸면 평행이동 확인
    ③ 내 예적분과 미분의 관계 + 미분 단원의 함수의 증가·감소0~2에서 증가, 2~5에서 감소하는 S(x)가 되도록 f(t) 만들기 (예: −t + 2, −t² + 4, t² − 8t + 12) → 공통점: f(2) = 0, 부호가 +에서 −로
    ④ 열린 질문적분과 미분의 관계 (f(x) < 0인 경우로 확장)f(x) < 0인 구간에서 S(x)의 변화와 이유를 1~2문장으로 설명 → 복사해 제출

    열린 질문 예상 답 유형: S'(x) = f(x) < 0이므로 감소 / 그 구간의 정적분은 음수라 더해질수록 S가 줄어듦 / 넓이가 ‘빠져나가는’ 구간 / S(x)의 값은 아직 양수일 수 있지만 감소함(값과 변화의 구분). 넓이 함수는 보통 f(t) ≥ 0일 때 도입하지만, 정적분을 부호 있는 넓이로 정의했으므로 S(x)를 ‘부호 있는 넓이’로 읽으면 f < 0 구간까지 자연스럽게 확장됩니다.
